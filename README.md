# منصة المذكرة البيداغوجية 📚

تطبيق React/Vite باللغة العربية لإعداد وتوليد المذكرات البيداغوجية لمادة علوم الطبيعة والحياة، مع دعم التصدير إلى Word، التخزين المحلي، والمزامنة الاختيارية مع Firebase.

## المتطلبات

- Node.js 18 أو أحدث
- npm 9 أو أحدث
- إعداد Firebase فقط عند الحاجة إلى تسجيل الدخول والمزامنة السحابية

## التشغيل

```bash
git clone https://github.com/Snv05/mizaniyati5.git
cd mizaniyati5
npm install
cp .env.example .env.local
npm run dev
```

يفتح التطبيق على: `http://localhost:3000`

## متغيرات البيئة

ضع القيم الفعلية في `.env.local` فقط، ولا تضعها في Git:

```dotenv
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_DATABASE_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.8-flash
```

`VITE_FIREBASE_DATABASE_ID` اختياري، ويُستخدم فقط عند استعمال قاعدة Firestore مسماة. أما `GEMINI_API_KEY` فهو متغير خادمي ولا يجب تسميته `VITE_GEMINI_API_KEY` إذا كان الهدف إبقاء المفتاح خارج حزمة المتصفح.

## المساعد الذكي وقاعدة المعرفة

للمساعد قاعدة معرفة مفهرسة محلياً من **المنهاج، الوثيقة المرافقة، دليل الأستاذ، والمذكرات**
(+ التدرج الرسمي ووثائق الأستاذ المرفوعة). مهمتها استخراج الأنشطة وتعليماتها وأجوبتها،
المشكلة، الفرضيات، إرساء الموارد، التقويم والتمارين، الوسائل، والجداول والبيانات —
مع عرض **عدة احتمالات موثقة** ومصدر كل احتمال.

**النص الرسمي حرفي لا ملخَّص:** تضم القاعدة 11 وثيقة وزارية مُفرَّغة حرفياً — منهاج 2016،
الوثيقة المرافقة (الجيل الثاني)، دليل الأستاذ (4AM)، المخططات السنوية 2022/2023 والمخطط السنوي
للتعلمات وآليات تنفيذه لكل مستوى — بمجموع **386 صفحة و≈469 ألف حرف**، ونسبة محارف شاذة **0.000 %**.
هذه الطبقة (`official`) لها الأولوية الأولى، وتُقتبس **برقم صفحتها**: «المنهاج — ص 47 (مصدر رسمي)».

- يعمل الاستخراج المباشر **بدون مفتاح ذكاء اصطناعي**؛ وعند توفر المفتاح تُرسل المقتطفات كسياق
  مُرقّم يقتبس منه النموذج بدل الاختلاق.
- الوثائق الرسمية تُحمَّل **كسولياً** عند فتح المساعد أو لوحة القاعدة، فلا تثقل الحزمة الرئيسية،
  ويمكن تعطيلها من اللوحة للاكتفاء بالملخصات المنهجية.
- أضف نص المنهاج أو الوثيقة المرافقة أو دليل الأستاذ أو مذكرتك من زر «القاعدة» داخل المساعد
  (لصق نص أو ملف `txt`/`md`) ليُفهرس مع المصادر الرسمية.
- نقاط البحث: `GET /api/knowledge/status` · `POST /api/knowledge/search` · `POST /api/knowledge/extract`.
- إعادة توليد المتن الرسمي: `/tmp/pdfenv/bin/python scripts/ingest_official_pdfs.py <مجلد PDF>`
  (يكتب `src/data/official/` — مجلد **مُولَّد**، لا يُحرَّر يدوياً).

التفاصيل الكاملة: [KNOWLEDGE_BASE.md](KNOWLEDGE_BASE.md).

## المحتوى المصدري حسب السنة

من قسم أي سنة اختر **المحتوى المصدري**:

- السنة الأولى تحتفظ بأرشيفها المصدري المتخصص.
- السنوات الثانية والثالثة والرابعة تعرض فهرساً موحداً للمذكرات والأنشطة والجداول والرسوم والتقويمات،
  مشتقاً مباشرة من قاعدة المذكرات الحالية، مع البحث وتصفية المقاطع وفتح المذكرة المرتبطة.
- تبويب **المصادر والصفحات** يحمّل النصوص الرسمية الخاصة بالسنة عند الطلب ويحافظ على أرقام صفحاتها الأصلية،
  ويتيح روابط الملفات المتاحة. بعض المراجع متاحة كملف PDF فقط ولا يُدّعى توفر تفريغ نصي لها.
- المحتوى المنظم ليس نقلاً حرفياً من PDF؛ يظل منفصلاً عن النصوص الرسمية، ولا تُختلق عناصر للأقسام الفارغة.
- **تصدير محتوى السنة JSON** يحفظ كامل مذكرات السنة وروابط المصادر وبيان الوثائق، وليس مجرد نتائج البحث.
- لكل السنوات تبويبات مستقلة ومتجاورة: **المحتوى المصدري** و**المخططات** و**دليل الأستاذ**،
  إلى جانب المذكرات والتدرج السنوي، على الحاسوب والهاتف.
- **المخططات** للسنوات الأربع تعرض افتراضياً التوزيع السنوي حسب الفصول، بصفوف تتحول إلى بطاقات على الهاتف،
  مع تبويبات للمقاطع والموارد والوثيقة الأصلية وقارئ PDF عند توفره محلياً. تدعم البحث وتصفية الفصل،
  وتوسيع/طي المقاطع والإحالة إلى الصفحة الأصلية وفتح مذكرات الأرشيف ذات الربط الصريح فقط.
  فهرس العرض في `src/data/yearPlanOutlines.ts` مستقل عن مدد دليل الكتاب؛ الإحصاءات تخص الوثيقة المختارة.
  داخل التوزيع السنوي وبطاقات المقاطع، تعرض `YearPlanUnitFields` الحقول الخمسة: **هيكلة الموارد المعرفية المستهدفة بالبناء والإرساء والإدماج، تقدير الحجم الزمني، آلية التنفيذ، معايير ومؤشرات التقويم، ملاحظات**.
  إحالات المقتطفات في `src/data/yearPlanFields.ts` تغطي 42 وحدة عرض في الوثائق الثماني، وتقرأ النص من الصفحات المفهرسة نفسها دون نسخه أو استنتاج الأعمدة من ترتيب النص المسطّح.
  هذه مقتطفات وليست تفريغاً كاملاً للأعمدة، مع روابط لكل صفحة والسياق الكامل. يبقى الحقل غير المفهرس معلناً كذلك، ولا يعني ذلك غيابه من الوثيقة.
  تُراجع بصمة الصفحة وحدود المقتطف قبل عرضه؛ إذا تغيّر المصدر تتوقف الإحالة عن العرض بدلاً من نقل محتوى عمود أو طبعة أخرى.
  تُحفظ ساعات وأسـابيع مخططات 2022/2023 كما في المصدر، دون اختراع أسابيع أو تواريخ تنفيذ تفصيلية،
  وتستثنى حصص الإدماج والاختبارات من مجموع ساعات بناء الموارد. يظل مقطع التنسيق الوظيفي للرابعة مقطعاً واحداً ممتداً عبر فصلين.
  تبقى طبعة 2021/2022 الاستثنائية بفهرس صفحات مستقل؛ مواردها ومددها غير الملخصة تُقرأ من النص الأصلي ولا تُستعار من الطبعة الأحدث.
  لا يُعرض رابط صفحة الوزارة بوصفه ملف PDF، ولا يُنشأ قارئ أو تنزيل لوثيقة غير مرفقة محلياً.
- **دليل الأستاذ** للسنوات الأولى والثانية والثالثة يستخدم نفس قالب العرض `TeacherGuideViewer`: ترويسة وأزرار PDF وطباعة،
  نفس التبويبات وبطاقات الإحصاءات والمقاطع المرقمة، ثم بطاقة لكل مورد بمفاهيمه الأساسية وسيرورة أنشطته وتوجيهه المنهجي.
  يدعم القالب فتح عدة مقاطع وتوسيع/طي كل المذكرات، مع إبقاء بيانات كل سنة وملفها وتبويب تقويمها مستقلة.
  يحتفظ دليل الثالثة بأنشطته وتصحيحات التمارين ومعجم المفاهيم القابلين للبحث وملفه الأصلي (96 صفحة).
  لا تُستحدث له مكتسبات قبلية أو مدد بديلة؛ تبقى بيانات السنة الرابعة كما هي.
  القراءة المنظمة للسنة الأولى مبنية على المقاطع الثمانية في مخطط 2022/2023، مع إحالات للصفحات، وليست كتاب دليل مستقل.
  تبقى مذكرات الأرشيف الـ27 منفصلة عن ملخصات الدليل والنص الرسمي؛ لا يُضاف مقطع النمو الأرشيفي إلى المقاطع الثمانية.

الفهرس في `src/services/sourceContent.ts` والواجهة المشتركة في `src/components/SourceContentViewer.tsx`،
دون نسخ جديدة من بيانات المذكرات أو ملفات PDF.

## بنية البيانات السحابية

```text
users/{userId}/data/{docId}
```

والمستندات المستخدمة هي:

- `config` ويحتوي على `config`
- `annualDist` ويحتوي على `items`
- `curriculum` ويحتوي على `lessons`
- `logbook` ويحتوي على `data`

## نشر قواعد Firestore

```bash
npm install -g firebase-tools
firebase login
firebase deploy --only firestore:rules
```

يجب التأكد من ربط Firebase بالمشروع الصحيح قبل النشر. لا يتم تشغيل اختبارات Firestore غير الموجودة في المستودع، لذلك لا يحتوي `package.json` على أمر اختبار وهمي.

## الأمان

- ملفات `.env.local` مستثناة من Git.
- لا تعتمد تهيئة Firebase على ملف إعدادات سري متتبع.
- يجب تدوير أي مفتاح Firebase ظهر في تاريخ Git سابقًا.
- مفاتيح Firebase الخاصة بالعميل ليست بديلًا عن قواعد Firestore؛ الحماية الفعلية تعتمد على Authentication وFirestore Rules.

### محادثة المساعد التربوي

- يبدأ المساعد بمحادثة حرة دون اختيار السنة أو المصدر. يبحث داخلياً في جميع المستويات، بما فيها التدرجات والمخططات والوثائق الرسمية ومحتوى المنصة والمذكرات ووثائق الأستاذ، دون التقيد بالصفحة المفتوحة.
- يحتفظ بموضوع الحوار والمسودة الأخيرة لمتابعات مثل «اجعله أكثر تفاعلية»، «أضف تجربة»، «أدخله في المذكرة». سجل موحد محلياً مع ترحيل غير هدّام للسجل القديم؛ «محادثة جديدة» تصفّر الحوار النشط فقط.
- تفاصيل المراجع والسنة مخفية في الرد العادي وتظهر عند طلبها. إدارة الوثائق والمهام الجاهزة والاستخراج المباشر متاحة عبر «أدوات المحادثة»، وليست خطوات إلزامية.
- الإدراج في مذكرة يعرض معاينة قابلة للتحرير واختيار المذكرة والموضع، ثم يتطلب تأكيداً صريحاً. يضيف المحتوى ولا يستبدل النشاط/التقويم السابق؛ النسخة المعدلة لا تحمل صفة نص رسمي غير معدل.
- عند تعذّر خدمة التوليد، يوضح المساعد أن المعروض محتوى مسترجع وليس تعديلاً جديداً على المسودة. تحليل المرفقات يحتاج مزوداً داعماً؛ لا يُدّعى تحليل ملف عند تعذره. البحث على الويب يستخدم أداة Gemini عند تهيئتها؛ لا يُدّعى الوصول للويب عند عدم وصول نتائج.
- **NotebookLM اختياري وغير متصل افتراضياً:** لا توجد واجهة عامة مفترضة أو مصادقة ضمنية. يمكن للمشرف تهيئة جسر HTTPS موثوق عبر `NOTEBOOKLM_BRIDGE_URL` و`NOTEBOOKLM_BRIDGE_TOKEN` على الخادم فقط. يستقبل `POST {query, limit: 6}` ويعيد `{excerpts: [{title, text, url?}]}`. الفشل/عدم التهيئة لا يعطل المحادثة؛ لا تُنسب إليه أي معلومات دون مقتطف فعلي. حد زمني 3 ثوان وحد استجابة 64KB؛ لا تُرسل ملفات أو سجلات الطلاب إلى الجسر. يستطيع الأستاذ أيضاً استيراد نصوصه المصدرة من الأداة عبر إدارة الوثائق القائمة.
- لا يفهرس المساعد مخازن الدرجات أو بيانات الطلاب الخاصة. الملخصات المشتقة من واجهات المنصة مصنفة كمراجع مساعدة، لا كنصوص وزارية حرفية.


## التقويم المحلي المستقل عن خدمات التوليد

زر **التقويم** داخل المذكرة يقرأ بياناتها تلقائياً ويشغّل `AssessmentEngine` دون طلب شبكة أو اختيار السنة من جديد. مدخل **التقويم وبنك التقويم** في التنقل يفتح الواجهة نفسها، مع إبقاء استيراد الأوراق ومذكرة التصحيح في أداة فرعية مستقلة.

### مسار الإنشاء

`LessonMemo → lessonData → concepts/keywords/objectives → IndexedDB bank → MatchingEngine → AssessmentRulesEngine → editable assessment → save → memo export`

- الأنواع الأربعة عشر معرفة في `src/assessment/types.ts`. المطابقة تتحقق من المستوى والمجال وتقيّم الدرس (+40)، الهدف (+30)، المفهوم (+20)، الكلمات (+10)، النوع (+10)، الصعوبة (+10)، مع وزن للوحدة والكفاءة. لا يكفي تطابق النوع/الصعوبة لقبول سؤال بعيد عن موضوع الدرس.
- يفضل محرك القواعد تنوع التفكير والأنواع وفق الأهداف، ولا يملأ العدد بأسئلة غير مرتبطة. يُعلن نقص العناصر بالرسالة: «لا توجد عناصر كافية لهذا الدرس. يمكنك إضافة عناصر جديدة إلى بنك التقويم.»
- تُشتق عناصر البداية من بيانات الأنشطة والتقويم لجميع المستويات، على دفعات كسولة لكل مستوى. القوالب تحتاج خلاصة علمية موجودة في المورد، ولا تخترع إجابات. تُستبعد أسئلة تحليل الوثائق التي لا يتوفر سندها، وتُضمّن الجداول النصية المتاحة. الأنواع الأخرى يمكن إضافتها وتحريرها من البنك.
- **استبدال** يبحث محلياً عن نفس الهدف والمفهوم ونوع متوافق وصعوبة قريبة. تُستبعد المعرّفات والبصمات النصية المستخدمة في نفس التقويم أو أي تقويم سابق للدرس، حتى بعد حذف السؤال. حفظ السجل مع رابط المذكرة وطابور المزامنة ذري داخل معاملة IndexedDB؛ يمنع كذلك حجز السؤال نفسه من تبويبين متزامنين.
- التحرير والحفظ في البنك لا يغيّران النسخ السابقة المحفوظة. الأسئلة المحذوفة من البنك تُعطّل (tombstone) حتى لا تعود بالمزامنة. «التقويمات المحفوظة لهذا الدرس» يتيح إعادة فتح نسخة سابقة.

### الحفظ والعمل دون اتصال

- قاعدة IndexedDB خاصة بالحساب (`local` عند عدم تسجيل الدخول) تحوي `assessmentItems`, `assessments`, `memoAssessments`, `assessmentTemplates`, `assessmentCategories` إضافة إلى مؤشرات محلية وطابور `outbox`.
- فهارس المستوى والكلمات ومعرّف الدرس/المذكرة؛ نتائج البنك 20 عنصراً في الصفحة. الاسترجاع يقرأ فهارس الكلمات بحدود ثابتة، ولا يضع كامل بنك الأسئلة في حالة React أو يحمّله كملف JSON.
- يُحفظ `assessment`, `assessmentItems`, `lessonId`, `memoId`, `createdAt`, `updatedAt` مع سجل الاستخدام. يعاد فتح السجل نفسه عند العودة إلى المذكرة. الإدراج يحدث نص التقويم المصدّر ويحفظ النص الأصلي منفصلاً في `assessmentOriginalTaqwim` دون المساس بالوثائق الأصلية.
- في بناء الإنتاج، يولّد `scripts/build-assessment-offline.mjs` عامل خدمة لقشرة التطبيق وملفات JS/CSS والخط العربي. **يجب زيارة التطبيق متصلاً وانتظار تخزين القشرة أول مرة**؛ بعد ذلك يمكن إعادة فتحه وإنشاء التقويم محلياً دون الإنترنت. لا يخزّن عامل الخدمة طلبات `/api` أو المصادقة أو ردود Firestore أو ملفات الأستاذ.
- تسجيل الدخول والمزامنة اختياريان. لكل حساب بنك محلي منفصل؛ بيانات وضع الضيف تبقى على الجهاز ولا تُرفع تلقائياً إلى حساب آخر. يلزم السماح بالتخزين في المتصفح. مسح بيانات المتصفح يمسح النسخة المحلية غير المتزامنة.

### المزامنة والأمان

`AssessmentCloudSync` يعيد محاولة المزامنة عند الاتصال، وبعد التعديلات، ودورياً. يرسل التغييرات إلى مجموعات المستخدم الخاصة في `users/{uid}/...`، ولا يحذف عملية من الطابور إلا بعد نجاحها وبشرط عدم وجود تعديل أحدث. تُقرأ التغييرات السحابية بصفحات 100 وبمؤشر `syncedAt` صادر من الخادم؛ لا يُسترجع بنك كل المستويات، بل عناصر المستويات المفتوحة فقط. تُدمج الصفحات في IndexedDB دون الكتابة فوق التعديلات المحلية المعلقة. الإنشاء دون اتصال لا ينتظر Firestore؛ وقد توجد تعديلات متزامنة على جهازين، لذلك تُحفظ سجلات التقويم القديمة للمراجعة.

يحدد `firestore.indexes.json` الفهرس المركب للمستوى ومؤشر المزامنة. قواعد `firestore.rules` تتحقق من ملكية المستخدم والمجموعات والحقول والأنواع والأحجام. تهيئة Firebase القائمة تكفي؛ **يجب نشر القواعد المحدثة على مشروعك**: `firebase deploy --only firestore:rules,firestore:indexes --project YOUR_PROJECT_ID`. لا توجد مفاتيح أو اتصالات مزوّد توليد في هذا المسار. ملف `firebase.json` يحدد القواعد ومحاكي Firestore للاختبار فقط، ولا يغيّر الاستضافة.

### النسخ والتصدير

- **نسخة التلميذ**: الأسئلة فقط، مع النقاط عند توفرها ومساحة الإجابة في المعاينة.
- **نسخة التصحيح**: الأسئلة والإجابات المسجلة وسلم التنقيط المتوفر، دون اختراع الإجابة الناقصة.
- معاينة RTL، طباعة بخط Cairo، وتصدير PDF كسول التحميل. تُحفظ النسخة المختارة في المذكرة، وتدخل في تصدير المذكرة القائم (PDF والطباعة وWord).
- استيراد TXT محلي بالكامل؛ قراءة Word/PDF النصي تستخدم قارئ الخادم المحلي القائم ولا ترسل إلى مزوّد توليد. الصور الممسوحة لا تُحلّل بالتخمين؛ تحتاج نصاً بديلًا. عناصر إجابة مذكرة التصحيح تُسترجع فقط عند تطابق السؤال نفسه، ولا يُستبدل جواب كتبه الأستاذ.

### الاختبارات

`npm run lint && npm test && npm run build`

تغطي اختبارات `assessmentEngine.test.ts` الإنشاء مع منع الشبكة، جميع المستويات، المطابقة والقواعد، منع التكرار والحجز الذري، الاستبدال، صفحات البنك، حفظ IndexedDB، طابور المزامنة، عزل الحسابات، النسخ والتصدير النصي وحدود الاعتماد. اختبار `assessmentFirestore.test.ts` يشغّل قواعد الأمان الفعلية فقط عند توفر `FIRESTORE_EMULATOR_HOST` (مثل `127.0.0.1:8080`)؛ غياب المحاكي يعني تخطيه، وليس ادعاء التحقق الحي أو نشر القواعد.
