Word (.docx) Embedded TrueType Fonts (Auto-generated)
=====================================================

These TrueType (.ttf) files are generated automatically from the locally
installed `@fontsource/*` packages by `scripts/prepare-docx-fonts.mjs`
(`npm run prepare:fonts`, also run on `postinstall` and `build`).

Each file merges the `-arabic-`, `-latin-`, and (when available) `-latin-ext-`
subsets into a single TrueType font (`sfntVersion = 0x00010000`, `glyf` outlines,
`OS/2 fsType = 0` installable/embeddable) so Arabic letters, digits,
punctuation, and scientific symbols render with the exact chosen font in Word.

Canonical files:
- PlaypenSansArabic-Regular.ttf  (Playpen Sans Arabic, 400)
- PlaypenSansArabic-Bold.ttf     (Playpen Sans Arabic, 700)
- Harmattan-Regular.ttf          (Harmattan, 400)
- Harmattan-Bold.ttf             (Harmattan, 700)
- Lateef-Regular.ttf             (Lateef, 400)
- Lateef-Bold.ttf                (Lateef, 700)
- Marhey-Regular.ttf             (Marhey, 400)
- Marhey-Bold.ttf                (Marhey, 700)
- Tajawal-Regular.ttf            (Tajawal, 400)
- Tajawal-Bold.ttf               (Tajawal, 700)
- Cairo-Regular.ttf              (Cairo, 400)
- Cairo-Bold.ttf                 (Cairo, 700)
